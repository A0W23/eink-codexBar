# Display task titles by default

Public installations will display task titles by default because identifying which task is running or has ended is the dashboard's primary value. Setup must clearly disclose before the first push that rendered task titles are uploaded as image pixels to ZECTRIX Cloud.

Users can enable a privacy mode that hides task titles while retaining activity states and counts. Project names, prompts, responses, reasoning, tool arguments, and plan text remain excluded from the MVP in both modes.
