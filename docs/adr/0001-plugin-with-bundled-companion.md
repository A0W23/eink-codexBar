# Distribute a Codex plugin with a bundled companion

The product will be installed and updated as a Codex plugin from a Git marketplace, while a bundled background companion performs continuous Codex observation, image rendering, and ZECTRIX publishing. This combines the discoverability and update path of a plugin with the independent lifetime needed to monitor multiple Codex Desktop tasks; a pure hook-only plugin and a separately installed macOS app were rejected because each loses one side of that trade-off.
